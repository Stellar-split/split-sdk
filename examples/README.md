# Examples

This directory contains runnable examples for the SDK. Each example is a small, self-contained project that demonstrates a specific feature.

## Running an example

```bash
cd examples/<example-name>
npm install
npm run dev
```

## Available examples

| Example | Description |
| --- | --- |
| `basic` | Minimal setup and first request |
| `auth` | Authenticated requests and token refresh |
| `streaming` | Streaming responses |
